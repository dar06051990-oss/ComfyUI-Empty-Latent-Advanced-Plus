# Changelog

## 1.0.0 — Community edition (2026-11-12)

- Expanded resolution presets to 67 across SD 1.5, SDXL, HD 720p, FHD 1080p, 2K, QHD and 4K.

- Added model-aware empty latents for 4-channel, 16-channel and 128-channel families.
- Added category filter displayed above Resolution.
- Fixed preset → Width/Height synchronization in Override mode.
- Kept legacy outputs and workflow widget serialization compatibility.
